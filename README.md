# Python Internship Projects
This repository contains practical projects developed during my internship, showcasing foundational skills in Python programming, file handling, and basic system automation. These projects demonstrate proficiency in developing functional scripts for real-world scenarios.

## Project Showcase
# 1. Hotel Management System
A command-line based application designed to manage fundamental hotel operations, including customer records and room availability.

Functionality:

Handles guest check-in and check-out.

Tracks room status (booked/available).

Data Handling: Utilizes file persistence to store and retrieve data (using hotel_data.xlsx), demonstrating proficiency in reading and writing external files.

Concepts Demonstrated: File I/O, Data Structure implementation (likely using lists/dictionaries for room management), and procedural programming logic.

# 2. Alarm Scheduler
A utility script that allows a user to set an alarm to trigger at a specific time, demonstrating automation and time-based logic.

Functionality:

Takes user input for the desired alarm time.

Continuously checks the current system time against the alarm time.

Triggers an audio alert (alarm.wav) when the time is reached.

Concepts Demonstrated: Threading/Time handling (using Python's time module), external library integration, and basic audio playback.

# 3. Simple Calculator
A basic calculator program capable of performing standard arithmetic operations.

Functionality:

Performs addition, subtraction, multiplication, and division.

Provides a command-line interface for interaction.

Concepts Demonstrated: User Input handling, conditional logic (if/elif/else), and function definition.
